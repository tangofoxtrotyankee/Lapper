# MVP Backlog and Priority

## P0 - product must work
- invoke from any normal Windows app
- identify active window
- obtain useful screen text
- present one-sentence orientation
- suggest relevant actions
- ask follow-up question
- copy response
- read response aloud
- never store screen content in cloud database/logs

## P0 - trust/security
- explicit user trigger
- password field suppression
- app exclusions
- prompt injection boundary
- action allowlist
- provider secrets backend-only
- authentication before external beta
- tenant RLS
- package signing before external beta

## P1 - product quality
- streaming response
- local OCR fallback
- image/screenshot fallback
- model routing
- source-block evidence
- user-created Laps
- default/per-app Lap preference
- feedback
- usage dashboard

## P1 - commercial readiness
- entitlements
- Stripe
- account/device management
- installer/update path

## P2 - later
- voice questions
- reminders/calendar actions
- team/shared Laps
- Mac app
- enterprise SSO
- local AI modes
- optional local encrypted history

## Explicitly deferred
- autonomous browser/computer agent
- email sending
- continuous monitoring
- cloud screen history
- embeddings of screen history
- agent frameworks
