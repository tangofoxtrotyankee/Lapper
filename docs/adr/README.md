# Architecture Decision Records

This folder holds ADRs following the policy in `CLAUDE.md`.

- Locked architecture decisions are listed in `CLAUDE.md`. They are not changed
  in code without an approved ADR.
- New ADRs are numbered sequentially: `NNNN-short-title.md` (e.g.
  `0001-switch-streaming-transport.md`).
- Copy `0000-template.md` to start a proposal.
- An ADR is a proposal until its status is set to `Approved` by the product
  owner. Do not implement the change before approval.
