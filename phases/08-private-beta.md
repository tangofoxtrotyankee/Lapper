# Phase 8 - Private Beta

## Goal
Ship safely to a bounded cohort and measure product behavior.

## Tasks
- Stripe plan scaffolding if charging
- entitlements
- private beta invite controls
- update mechanism
- feedback UX
- product analytics metadata only
- performance dashboard
- AI cost dashboard
- crash/error monitoring
- DPIA/privacy review completion
- incident response runbook
- model eval release gate

## Acceptance criteria
- beta user can install, sign in, invoke Lapper and update safely
- usage limits work
- account deletion works for cloud metadata
- actionable feedback can be tied to request metadata without storing screen content by default
- metrics report action-take rate and time-to-first-useful-response
