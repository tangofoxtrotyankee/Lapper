# Phase 7 - Laps

## Goal
Introduce reusable personal behaviours without turning Lapper into an autonomous agent.

## Tasks
- Lap data model/API
- built-in Work, Simple, Read and Extract presets
- user-created Lap configuration
- preferred action ordering
- optional per-app preferred Lap stored locally first
- versioning

## Acceptance criteria
- Lap instructions cannot override security/system policy
- malformed config rejected
- a user can create/update/delete a Lap
- switching Laps materially changes orientation/action behavior
